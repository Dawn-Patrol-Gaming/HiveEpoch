# HiveEpoch
Replacement for Arma 2 OA DayZ Epoch HiveExt.dll

Direct port of https://github.com/icomrade/icomradeHiveEpoch

This version of HiveExt does not require C++ runtimes, database connectivity dependencies or memory management dependencies like tbb.dll or tbbmalloc.dll like the original(s).

This is a direct replacement that can replace the original hiveext.dll. 

This also provides the same structure and format as extdb2.dll for Arma 3, enabling you to access custom SQL from an additional ini file named dbfunctions.ini

In the releases is a copy of HiveExt.dll and a testing app. Since most people won't be able to compile from source unless they own a copy of Delphi and the associated 3rd party components: Devart UniDAC, I've attached precompiled binaries to this repo.
