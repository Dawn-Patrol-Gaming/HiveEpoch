HiveExt.dll:
This is the replacement for HiveExt.dll, place this in your Arma server where the original HiveExt.dll went (usually the server mod folder).

This will search for HiveExt,ini and dbfunctions.ini on load, you want to keep those two files together if possible.
If you are using template.sqf for custom object loading from the database at server startup, you want to place template.sqf in the same folder as HiveExt.dll.

dlltest.exe:
This app allows you to load the dll and test calls from Arma to the dll and see the output.
This basically is like calling from inside SQF:
_dbcall = "CHILD:302:11:false:";
_data = "hiveext" callExtension _dbcall;

or non-hive call:
_dbcall = format["initialize:%1",Debug_DBFunctions];
_data = "hiveext" callExtension _dbcall;

This will show the response, good for debugging any custom sql you have specified in dbfunctions.ini. You shouldn't need to test any hive calls since they work just the same way as the original HiveExt.dll
